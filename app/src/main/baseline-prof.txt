# NexaSense startup baseline profile
# ----------------------------------
# Bundled by AGP into the APK and applied by androidx.profileinstaller on
# Android 13+ (ignored gracefully on Android 12). It pre-compiles the
# cold-start hot path: application, activity, theme, navigation, the home
# screen and the core sensor engines, plus the well-known AndroidX startup
# cost centers (AppCompat delegate inflation, Compose recomposition loop,
# navigation). Format follows AndroidX baseline profile syntax: HSPL marks
# hot-startup rules; **->**(**)** matches every method of a class.
